## GitHub Pages

The site is served from the root `index.html` and deployed automatically when
changes are pushed to `main`.

Once the first deployment finishes, the site will be available at:

<https://hanhuutrung22130302.github.io/adb-treeDictionary/>

To deploy manually, run the **Deploy GitHub Pages** workflow from the
repository's **Actions** tab.
